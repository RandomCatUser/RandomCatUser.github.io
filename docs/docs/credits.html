Tools & Technologies Used

This project was built from scratch using modern, lightweight, and highly efficient tools.

  • HTML5 & CSS3: The foundational structure and custom styling, utilizing modern features like CSS variables and backdrop filters.
  • Tailwind CSS: The primary utility-first CSS framework used for rapid UI development and responsive design.
  • Vanilla JavaScript: All interactivity (theme switching, modals, accordions, particle effects) is written in pure JS with no heavy libraries.
  • VS Code: The code editor used for development, paired with GitHub Copilot for suggestions.
  • Git & GitHub: Version control and source code hosting.
  • GitHub Pages: Free and seamless static site hosting directly from the repository.
  • Figma: Used for prototyping layouts, picking color palettes, and testing dark/light mode contrasts.
  • Chrome DevTools: Essential for debugging layout issues, testing mobile responsiveness, and profiling animations.

How to Clone This Repository

Cloning the repository allows you to get a full local copy of the "My Universe" project.

Steps to Clone:

  1. Install Git: If you don't have Git installed, download it from git-scm.com/downloads.
  2. Open your Terminal/Command Prompt: Navigate to the directory where you want to save the project. 
    cd path/to/your/desired/directory
  3. Clone the Repository: Use the git clone command followed by the repository URL. 
    git clone https://github.com/RandomCatUser/RandomCatUser.github.io.git
  4. Navigate into the Project: 
    cd RandomCatUser.github.io
  5. You now have a local copy of the repository! Open index.html in your browser to view it.
