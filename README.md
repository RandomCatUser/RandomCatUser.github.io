# Portfolio Site

This is my personal portfolio site built with **HTML**, **Tailwind CSS**, and **JavaScript**. It’s currently under development.

## Live URL
[Connect](https://randomcatuser.github.io/)

## Tech
- HTML
- Tailwind CSS
- JavaScript

## How to Run Locally
1. Open **`index.html`** in your browser (this is the main entry point).
2. If you edit UI styles using Tailwind, rebuild the Tailwind output as described below.

## Tailwind (Optional)
If you want to update Tailwind styles locally:

### Watch / Develop
```bash
npm run start:tailwind
```

### Build (Production)
```bash
npm run build:tailwind
```

## Project Structure (Quick Look)
- `index.html` – main page
- `index.js` – front-end logic
- `css/` – Tailwind source + generated CSS files
- `assets/` – images, music, and other media
